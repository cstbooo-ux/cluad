# 《我不知道》PV

沿用第二版（`mv2/`）的纸面孔版印刷风格，换成荧光粉、青绿、柠檬黄三色油墨，主角是一个问号小人。

- `wobuzhidao_pv.mp4`：成片（1920×1080，30fps，51.85 秒，112 BPM 卡点）
- `render.py`：分镜和时间线（歌词时间读取 `lyrics.srt`）
- `engine.py`：渲染引擎（油墨叠印、网点、镜头、字体排版），派生自 `mv2/render.py`
- `fetch_fonts.sh`：下载字体

## 重新渲染

```
pip install numpy opencv-python-headless pillow imageio-ffmpeg
./fetch_fonts.sh
MV_AUDIO=/path/to/song.wav python3 render.py video out.mp4
python3 render.py stills 10.6 29.5        # 只出静帧到 stills/
```

每句歌词内部的逐字时间按 SRT 的起止时间平均分配（`syl()`），改 `lyrics.srt` 即可调整。
