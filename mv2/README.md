# 风筝 MV（第二版，前 30 秒）

纸面孔版印刷（Risograph）风格。只用蓝、红、黄三种油墨，带网点、套色错位和线条抖动。
全片以「风筝」串起来：被风吹走，也被线拴住。

- `fengzheng_mv.mp4`：成片（1920×1080，30fps，147 BPM 卡点，音频在 29–30 秒淡出）
- `render.py`：逐帧渲染器，画面全部由代码生成
- `fetch_fonts.sh`：下载渲染用的字体（思源黑体、得意黑、霞鹜文楷）

## 分镜

| 时间 | 歌词 | 画面 | 镜头 |
|---|---|---|---|
| 0–1.8 | 前奏 | 印刷对位标，风筝被线拽进画面，网点云 | 从特写拉远 |
| 1.8–5.5 | 吹散了天 / 吹乱了地 / 吹远了 / 哦~哦 | 字被吹散往上飞、云被撕开；红字乱跳后掉落；字带残影缩向远方；「哦~哦」骑在风线上；大风横扫转场 | 仰起、下摇加旋转、推进、横移 |
| 5.5–8.4 | 啊 / 有些话还没说出口 | 俯拍书桌上的稿纸，红色印章「啊」砸下，字一格格打进格子，「没说出口」被涂黑，稿纸折成风筝 | 俯视、缓推，折纸后拉远 |
| 8.4–12.8 | 就随着晚风 / 飘呀×3 / 飘到远方 | 黄昏网点天空、三层剪纸山丘、飞鸟、纸屑，字沿风的波浪排开，「飘到远方」越来越小 | 摇上天空，跟随风筝后拉升高（多层视差） |
| 12.8–17.0 | 我却成了 / 阶下囚 | 线拴在地上的木桩，铁栏砸下，每两拍换一次配色 | 顺着线下摇，希区柯克变焦 |
| 17.0–18.8 | 可能是我 / 不懂 | 横线本上手写，「不懂」被红笔圈住，加一个问号 | 手持特写 |
| 18.8–21.4 | 可是我们 / 没什么 / 不同 | 画面左右分屏，字跨过中线自动反色，两只镜像风筝，每半拍左右互换 | 3D 翻页转场 |
| 21.4–25.0 | 故事 / 走呀×4 / 走到了尽头 | 电线杆、台阶、脚印，一路走到纸张边缘 | 横移长镜头，逐步跨拍，甩镜头转场 |
| 25.0–27.0 | 还有个人 / 却不肯 | 竖排文字，剪影人握着一根越绷越紧的线 | 缓慢推近 |
| 27.0–29.0 | 放手 | 每拍换一种构图：放射线、满屏滚字、网点圆、黑底斜排、黄底速度线 | 冲击震动、套色错位 |
| 29.0–30.0 | 结尾 | 风筝还在天上，线还连着那个人 | 缓慢拉远 |

## 重新渲染

```
pip install numpy opencv-python-headless pillow imageio-ffmpeg
./fetch_fonts.sh
MV_AUDIO=/path/to/song.wav python3 render.py video out.mp4
python3 render.py stills 5.5 13.8 27.0     # 只出静帧到 stills/，检查用
```

歌词时间写在各场景函数（`s01`、`s2` …… `s8a`）里，节拍网格由文件开头的 `BPM` 和 `PH` 决定。
