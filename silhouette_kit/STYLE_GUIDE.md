# 剪影卡点动画 · 画风规范（Style Guide）

这份文档描述《二战剪影》这套画风的规则，用来复刻到其他题材的动画（其他战争、城市、历史、音乐 MV 等）。
可复用的代码都在 `silhouette_kit/`：人物 `figure.py`、道具 `props.py`、效果 `fx.py`、画布与后期 `core.py`、音效 `sfx.py`。
场景、时间线、音效编排的写法参考示例项目 `projects/ww2_silhouette/`（`scenes.py`、`render.py`、`soundtrack.py`）。

---

## 1. 核心概念

- **一个纯黑剪影人物，从左往右一直走**，固定在画面偏左（x = 720 / 1920），背景在身后按拍子切换。
- 人物是"无名的普通人"：每个场景里完全一样，只换装束（平民 ↔ 士兵）。
- **画面 = 扁平剪影插画**：没有描边、没有纹理贴图，靠"形状轮廓 + 分层明暗 + 天空渐变"讲故事。
- 节奏第一：切换、爆炸、闪白、脚步都落在拍子上。

## 2. 画面规格

| 项 | 值 |
|---|---|
| 分辨率 | 1920×1080，16:9 |
| 帧率 | 30fps |
| 地平线（人物脚底） | `GY = 870` |
| 人物位置 / 高度 | `FIG_X = 720`，`FIG_H = 430`（约画面高 40%） |
| 后期 | 胶片颗粒（6 张固定颗粒图轮换，每 3 帧换一次）+ 暗角 |

## 3. 分层结构（从后往前）

| 层 | 视差系数 | 内容 | 明度 |
|---|---|---|---|
| 天空 | 0 | 竖向渐变 + 太阳/月亮光晕 + 天气光（探照灯、日出光束） | 最亮 |
| 远景 | 0.03–0.1 | 地标剪影（埃菲尔、大本钟、金字塔、宝塔桅楼）、远山、烟柱 | 接近天空色，略暗 |
| 中景 | 0.15–0.5 | 楼房立面、坦克、火车、飞机、其他人物 | 中等暗 |
| 地面 | 1.0 | 人物站立的地面带（深色或雪白）、地面细节 | 深 |
| **主角** | 1.0 | 纯黑剪影 + 脚下接触阴影 | 纯黑 `#000` |
| 前景遮挡 | 1.7 | 草丛、路灯、沙袋、拒马、立柱、蕨叶等，从主角前面扫过 | 近黑 `#040304` |
| 天气 | — | 雨、雪、沙尘、火星、灰烬，永远在最上层 | — |

**规则**：
- 越远越接近天空色（空气透视），越近越黑。
- 主角身后（x 600–850、y 440–870）必须是比主角亮的颜色，保证剪影一眼看清。
- 地面带的顶边就是主角脚底线；雪地、沙地可以是亮色，其余一般深色。
- 前景遮挡物要伸出地平线以上，否则在深色地面里看不见。

## 4. 配色

每个场景一套 3–5 色的天空渐变 + 同色系的剪影色，**同一场景内不混冷暖**。

| 情绪 | 天空渐变（上 → 地平线） | 剪影色 |
|---|---|---|
| 平静黄昏 | `#2d3b5c → #8c6a78 → #e39a6a → #f6cf8c` | `#5e3e4c`、`#2a1a22` |
| 雨夜城市 | `#161a2a → #3d3d55 → #7a6a78 → #a08a8a` | `#24212e`，亮窗 `#f5b76a` |
| 雪地冷色 | `#6f7c8a → #aab4bc → #dde2e3` | `#5d6873`、`#2a3139` |
| 落日海面 | `#4a1820 → #b0433a → #ec8c55 → #f6c27d` | `#30161a` |
| 沙漠烈日 | `#3e7fb8 → #a8c8d8 → #f4e0b0` | `#5a3a1c`，沙 `#9a6430` |
| 战火（B 版） | `#2a0f10 → #8a2e20 → #e0612f → #ff9a45` | `#1c0c0a`，火 `#ffb347` |
| 尾声日出 | `#5e6f98 → #b89aae → #f2c3a4 → #fde6bc` | `#6f5866` |

**A/B 两个版本**：同一个地点，A 是平静版（冷、静、有生活气），B 是战火版（整体转红橙，加火焰、烟、爆炸、曳光弹）。

## 5. 人物规则（`figure.py`）

- 侧脸朝右，头约占身高 1/7.8；侧脸要有额头、眉骨、鼻梁、圆鼻尖、上下唇、下巴，**下半张脸往回收**（嘴唇和下巴在鼻尖后面）。
- 脖子短，不往前探。
- 腿有大腿、膝盖、小腿肚的起伏；鞋有鞋跟和足弓空隙。
- 平民：礼帽（前压后翘的帽檐）+ 长风衣（立领、收腰、后开衩）+ 手提箱。
- 士兵：圆顶头盔 + 军装 + 马裤高筒靴 + 背包毯子卷 + 步枪；冲锋时步枪平端带刺刀。
- 走路：每拍一步（一个步态周期 = 2 拍）；跑步：每半拍一步。
- **不能浮空**：地面滚动用 `travel()`，跟着实际着地的鞋底点走；脚下永远有接触阴影。
- 其他人物（群众、冲锋的士兵）用同一个 `figure()`，只换颜色和大小，越远越浅。

## 6. 道具与细节（`props.py`）

- 全部是**纯色剪影**，细节靠轮廓：檐口、烟囱、天线、炮管、窗洞（镂空透出天空）、残破的锯齿顶。
- 地标要一眼认出国家，但**不画旗帜和任何政治标志**（卐字、旭日旗等），用建筑、军装、载具轮廓暗示。
- 已有：欧式楼房（可加战损）、废墟墙、瓦砾、路灯、电线杆、埃菲尔铁塔、大本钟、议会大厦、圆顶教堂、防空气球、圣瓦西里、克里姆林宫墙、金字塔、棕榈、柏树、风车、农舍、修道院、谢尔曼、四号坦克风格、T-34、卡车、蒸汽机车、登陆艇、战斗机、轰炸机、航母舰岛、机库、塔台、风向袋，以及前景道具（草丛、铁丝网桩、沙袋、木箱、油桶、缆桩、绳圈、岩石、蕨叶、立柱、行李、油桶）。

## 7. 环境效果（`fx.py`）

**天气跟着地点走**：冬天下雪、雨林和巴黎下雨、沙漠只有烈日加热浪和扬尘（没有雨雪）、海上有反光和浪花。
战火版加：火焰、滚动烟柱、爆炸（火球 → 黑烟 → 碎片）、曳光弹、火星、灰烬、水柱、枪口火光、探照灯。
烟、火都画成"合并的扁平形状"，不要一个个半透明圆叠在一起。

## 8. 节奏与镜头语言

| 段落 | 切换密度 | 镜头 |
|---|---|---|
| 开场 | 4 拍 1 切 | 黑屏淡入 |
| 铺垫 | 2 拍 1 切 | 每次切换轻微推近（3%），每拍微弱脉冲 |
| 高潮 | 1 拍 1 切 | 推近 4.5% + 震屏 + 每小节闪白；进入高潮时大闪白 |
| 冲锋 | 1 拍 1 切 + 半拍闪白 | 人物跑动，端枪冲锋 |
| 尾声 | 4 拍 1 切 | 闪白后回到平静，最后一拍渐黑 |

切点公式：第 k 拍在第 `round(k × 60/BPM × 30)` 帧，误差不到半帧。换歌只改 `render.py` 里的 `BPM` 和时间线。

## 9. 声音（`silhouette_kit/sfx.py` + 项目里的 `soundtrack.py`）

- 全部程序合成，无版权素材；输出环境 / 事件 / 脚步三条分轨 + 总混音 + 节拍器。
- 环境声在切点上和画面一起硬切；高潮段每拍一声爆炸，左右声道跟画面位置；脚步按地面材质（雪、石板、湿路、沙、甲板、泥、瓦砾）。
- 高潮前 4 拍蓄力；结尾耳鸣 + 声音从闷到清。

## 10. 做一个新动画的步骤

最快的方式：复制 `projects/ww2_silhouette/` 为新项目文件夹，然后：


1. 定 BPM 和总拍数，在 `render.py` 里写时间线 `SHOTS`（起始拍、拍数、场景名、A/B、人物装束）。
2. 在 `scenes.py` 里新增场景函数：按第 3 节分层，最后调用 `hero(ctx, S)`，再画天气。
3. 在 `foreground()` 里给新场景加一两个前景遮挡物。
4. `python3 render.py sheets` 出全部场景总览图，先确认画风。
5. 在 `soundtrack.py` 的 `SURF` 和 `shot_audio()` 里给新场景配脚步材质和环境声。
6. `python3 render.py video out` 出片（带音效版 + 节拍器版 + 分轨）。
