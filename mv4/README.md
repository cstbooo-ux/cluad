# 《我不知道》PV（暗版）

同一首歌、同一份歌词，换一种读法：「我不知道」不是轻松，而是麻木和逃避。
复印机 / 碳粉风格：灰黄旧纸、黑色碳粉，只有「被问」的地方用暗红（红笔圈、日历、计数器）。
主角是一个脸上贴着一张印有问号的纸的学生剪影。

- `wo_buzhidao_dark.mp4`：成片（1920×1080，30fps，51.85 秒；画面内的动作按 12fps 走，刻意显得冷、卡顿）
- `render.py`：分镜和时间线（歌词时间读取 `lyrics.srt`）
- `engine.py`：渲染引擎，派生自 `mv3/engine.py`，换成碳粉配色

## 核心结构：复印件的复印件

六次「我不知道」用同一个构图（同一张桌子、同一个人），每次都像又复印了一遍：
更糊、对比更硬、碳粉渣和竖向条纹越来越多、画面微微歪斜（`render.py` 里的 `CHORUS` 和 `degrade()`）。
结尾闹钟响起，复印机的灯再扫一遍，吐出和开头一样的空白试卷：第二天照旧，循环。
